# FPS Animation Rig

Artist-friendly full-body FPS animation rig in Blender for the Mixamo-based `LowPolyMale` character, exporting Unity Humanoid clips.

- `Blender/FPS_Rig.blend` – the rig. Open it and animate.
- `Docs/ANIMATOR_GUIDE.md` – how to animate and export.
- `Docs/RIG_PLAN.md` – source inspection and rig design.
- `Exports/` – exported FBX clips (`Example_FPS_Ready.fbx` is a test clip).
- `Source/LowPolyMale_Rigged.fbx` – untouched reference character.
- `Blender/scripts/` – one-time rig build script and the export helper (also embedded in the .blend).
